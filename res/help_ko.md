# mendo 사용 안내

가볍고 빠른 Markdown 뷰어입니다.

## 파일 열기

- 파일을 창으로 끌어다 놓기
- `Ctrl+O`를 누르거나 제목 표시줄의 파일 열기 버튼을 클릭하여 파일 대화 상자 열기
- 왼쪽 파일 창에서 파일 클릭
- `Ctrl+N`을 누르거나 오른쪽 클릭 메뉴의 "새 창"을 선택하여 현재 파일을 새 창에서 열기
- 파일 창의 항목을 가운데 클릭 또는 `Ctrl+클릭`하거나, 오른쪽 클릭 메뉴의 "새 창에서 열기"를 선택하여 해당 항목을 새 창에서 열기

## 스크롤

- 마우스 휠로 부드럽게 스크롤
- `Up` / `Down` 화살표 키로 한 줄씩 스크롤
- `Page Up` / `Page Down`으로 한 페이지씩 스크롤
- `Home` / `End`로 처음이나 끝으로 이동

## 뒤로 / 앞으로

- `Alt+Left` / `Alt+Right`
- 마우스 측면 버튼 (뒤로 / 앞으로)
- 마우스 오른쪽 버튼을 누른 채 왼쪽이나 오른쪽으로 드래그 (마우스 제스처)
- 터치패드에서 가로로 스와이프
- 오른쪽 클릭 메뉴의 ← → 버튼
- 본문 오른쪽 아래의 ← → 버튼 (기록이 있을 때 표시)

## 검색

- `Ctrl+F`를 누르거나 제목 표시줄의 검색 버튼을 클릭하여 검색 표시줄 열기
- `Enter` / `F3`으로 다음 일치 항목으로 이동
- `Shift+Enter` / `Shift+F3`으로 이전 일치 항목으로 이동
- `Ctrl+G` / `Ctrl+Shift+G`로도 다음 / 이전 일치 항목으로 이동 가능
- 대/소문자 구분 전환
- 모든 일치 항목 강조 표시 전환
- `Escape`나 `Ctrl+F`로 검색 표시줄 닫기

| `Ctrl+O` | 파일 열기 |
| `Ctrl+N` | 새 창 열기 |
| `Ctrl+C` | 선택한 텍스트 복사 |
| `Ctrl+Shift+C` | 선택한 텍스트를 서식 있는 HTML로 복사 |
| `Ctrl+A` | 모두 선택 |
| `Ctrl+1` | 파일 창 표시 / 숨기기 |
| `Ctrl+2` | 목차 창 표시 / 숨기기 |
| `Ctrl++` / `Ctrl+-` | 확대 / 축소 |
| `Ctrl+0` | 확대/축소 초기화 |
| `Ctrl+마우스 휠` | 포인터 아래 영역 (본문, 파일 창, 목차 창) 확대 / 축소 |

| `F3` / `Ctrl+G` | 다음 일치 항목 (검색 표시줄 안에서는 `Enter`도 가능) |
| `Shift+F3` / `Ctrl+Shift+G` | 이전 일치 항목 (검색 표시줄 안에서는 `Shift+Enter`도 가능) |
| `Alt+Left` / `Alt+Right` | 뒤로 / 앞으로 |
| `F1` | 이 도움말 표시 |
| `F5` | 파일 다시 불러오기 |

| `Page Up` / `Page Down` | 페이지 단위 스크롤 |
| `Home` / `End` | 처음 / 끝으로 이동 |
| `Escape` | 선택 해제 / 검색 표시줄 닫기 |

## 팁

- **목차 창**: 목차의 제목을 클릭하면 해당 위치로 이동합니다
- **파일 창**: 위쪽 버튼으로 현재 파일이 있는 폴더로 이동하거나 목록을 새로 고칩니다
- **창 표시 / 숨기기**: 제목 표시줄 버튼이나 오른쪽 클릭 메뉴에서 파일 창과 목차 창을 전환합니다
- **자동 다시 불러오기**: 열려 있는 파일이 바뀌면 자동으로 다시 불러오고 바뀐 위치로 스크롤합니다
- **링크**: 외부 링크를 클릭하면 브라우저에서 열리고, 페이지 내 링크를 클릭하면 해당 제목으로 이동하며, Markdown 파일 링크를 클릭하면 그 파일이 열립니다. Markdown 파일이나 제목으로 가는 링크를 가운데 클릭 또는 `Ctrl+클릭`하면 새 창에서 열립니다
- **텍스트 선택**: 드래그하여 범위를 선택하고, 두 번 클릭하여 단어를 선택합니다
- **코드 블록 복사**: 코드 블록 오른쪽 위의 복사 버튼을 클릭합니다
- **HTML로 복사**: `Ctrl+Shift+C`를 누르거나 오른쪽 클릭 메뉴에서 "HTML로 복사"를 선택하면 제목, 강조, 링크 등의 서식을 유지한 채 HTML 서식 있는 텍스트를 클립보드에 넣습니다. Word나 Outlook에 붙여 넣으면 서식이 유지됩니다.
- **다이어그램 저장 / 복사**: Mermaid 다이어그램 위에 마우스를 올리고 오른쪽 위에 나타나는 버튼으로 PNG로 저장하거나 클립보드에 복사합니다
- **다이어그램 크게 보기**: 같은 오른쪽 위 버튼으로 다이어그램을 별도 창에서 엽니다. 휠이나 드래그로 이동하고, 창 오른쪽 위의 버튼으로 확대·축소합니다. 파일을 저장하면 열려 있는 다이어그램도 갱신됩니다
- **편집기에서 열기**: 오른쪽 클릭 메뉴에서 "편집기에서 열기"를 선택하면 기본 편집기로 현재 파일을 엽니다
- **설정**: 제목 표시줄의 톱니바퀴 버튼으로 설정을 열어 표시 언어를 바꾸거나 (바로 적용) 다이어그램 캐시를 삭제할 수 있습니다
- **다크 모드**: 제목 표시줄 버튼이나 오른쪽 클릭 메뉴에서 전환합니다
- **영역별 확대/축소**: 본문, 파일 창, 목차 창은 각각 따로 배율을 가집니다. 오른쪽 클릭 메뉴의 "확대/축소" 줄 (−, +, 초기화)에서도 메뉴를 연 채로 조정할 수 있습니다
- **파일 창 / 목차 창 너비 조정**: 본문과의 경계를 드래그하여 너비를 조정합니다
- **창 위치 초기화**: 작업 표시줄 버튼을 마우스 오른쪽 버튼으로 클릭하고 "창 위치 초기화"를 선택합니다
