# mendo User Guide

A lightweight, high-speed Markdown viewer.

## Opening Files

- Drag & drop a file onto the window
- Press `Ctrl+O` or click the open file button in the title bar to open a file dialog
- Click a file in the left file pane

## Scrolling

- Mouse wheel for smooth scrolling
- `Up` / `Down` arrow keys for line-by-line scrolling
- `PageUp` / `PageDown` for page-by-page scrolling
- `Home` / `End` to jump to the top or bottom

## Back / Forward

- `Alt+Left` / `Alt+Right`
- Mouse side buttons (back / forward)
- Right-click and drag left or right (mouse gesture)
- Horizontal swipe on a touchpad

## Search

- Press `Ctrl+F` or click the search button in the title bar to open the search bar
- `Enter` / `F3` to jump to the next match
- `Shift+Enter` / `Shift+F3` to jump to the previous match
- `Ctrl+G` / `Ctrl+Shift+G` also navigate to next / previous match
- Toggle case sensitivity
- Toggle highlight all matches
- `Escape` to close the search bar

| `Ctrl+Shift+C` | Copy selected text as formatted (HTML) |
| `Ctrl+A` | Select all |

| `Ctrl+0` | Reset zoom |

## Tips

- **TOC Pane**: Click a heading in the TOC to jump to it
- **File Pane**: Use the buttons at the top to go to the current file's folder or refresh the list
- **Show / Hide Panes**: Toggle the file pane and TOC pane from the title bar buttons or the right-click menu
- **Live Reload**: When the open file changes, it is reloaded automatically and scrolled to the changed position
- **Links**: Click to open external links in your browser / jump to headings in the page
- **Code Block Copy**: Click the copy button at the top-right of a code block
- **Copy as HTML**: Press `Ctrl+Shift+C` or select "Copy as HTML" from the right-click menu to put HTML rich text on the clipboard while preserving headings, emphasis, links, and more. Pasting into Word or Outlook keeps the formatting.
- **Diagram Save / Copy**: Hover over a Mermaid diagram or math block and use the buttons that appear at its top-right to save it as PNG or copy it to the clipboard
- **Open in Editor**: Select "Open in Editor" from the right-click menu to open the current file in your default editor
- **Settings**: Click the gear button in the title bar to switch the display language (applied immediately) or clear the diagram cache
- **Dark Mode**: Toggle from the title bar button or the right-click menu
- **Per-Area Zoom**: The document, file pane, and TOC pane each have their own zoom level. You can also change it from the "Zoom" row (−, +, reset) in the right-click menu, which stays open while you adjust
- **Pane Resizing**: Drag the pane border to resize
- **Reset Window Position**: Right-click the taskbar button and choose "Reset Window Position"
