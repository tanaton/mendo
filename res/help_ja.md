# mendo 操作ガイド

軽量・高速な Markdown ビュアーです。

## ファイルを開く

- ファイルをウィンドウにドラッグ＆ドロップ
- `Ctrl+O` またはタイトルバーのファイルを開くボタンでファイル選択ダイアログを表示
- 左側のファイルペインからクリック

## スクロール

- マウスホイールでスムーズスクロール
- `↑` / `↓` キーで行単位スクロール
- `PageUp` / `PageDown` でページ単位スクロール
- `Home` / `End` で先頭・末尾へジャンプ

## 戻る・進む

- `Alt+←` / `Alt+→`
- マウスのサイドボタン（戻る/進む）
- 右クリックしながら左右にドラッグ（マウスジェスチャー）
- タッチパッドの水平スワイプ

## 検索

- `Ctrl+F` またはタイトルバーの検索ボタンで検索バーを表示
- `Enter` / `F3` で次のマッチへ移動
- `Shift+Enter` / `Shift+F3` で前のマッチへ移動
- `Ctrl+G` / `Ctrl+Shift+G` でも次/前のマッチへ移動可能
- 大文字/小文字の区別を切替可能
- 全マッチのハイライト表示を切替可能
- `Escape` で検索バーを閉じる

## キーボードショートカット

| キー | 機能 |
|---|---|
| `Ctrl+O` | ファイルを開く |
| `Ctrl+C` | 選択テキストをコピー |
| `Ctrl+A` | すべて選択 |
| `Ctrl+1` | ファイルペインの表示切替 |
| `Ctrl+2` | 目次ペインの表示切替 |
| `Ctrl++` / `Ctrl+-` | ズームイン / ズームアウト |
| `Ctrl+0` | ズームをリセット |
| `Ctrl+F` | 検索バーを開く |
| `F3` / `Shift+F3` | 次/前のマッチへ移動 |
| `F1` | このヘルプを表示 |
| `F5` | ファイルを再読み込み |
| `Escape` | 選択を解除 / 検索バーを閉じる |

## 便利な機能

- **目次ペイン**: 右側の目次から見出しをクリックしてジャンプ
- **コードブロックのコピー**: コードブロック右上のコピーボタンをクリック
- **ダイアグラムの保存**: Mermaidダイアグラム右上の保存ボタンでPNG画像として保存
- **ダークモード**: 右クリックメニューから切替
- **ペイン幅の調整**: ペイン境界をドラッグしてリサイズ
