# mendo 操作ガイド

軽量・高速な Markdown ビュアーです。

## ファイルを開く

- ファイルをウィンドウにドラッグ＆ドロップ
- `Ctrl+O` またはタイトルバーのファイルを開くボタンでファイル選択ダイアログを表示
- 左側のファイルペインからクリック

## スクロール

- マウスホイールでスムーズスクロール
- `↑` / `↓` キーで行単位スクロール
- `PageUp` / `PageDown` でページ単位スクロール
- `Home` / `End` で先頭・末尾へジャンプ

## 戻る・進む

- `Alt+←` / `Alt+→`
- マウスのサイドボタン（戻る/進む）
- 右クリックしながら左右にドラッグ（マウスジェスチャー）
- タッチパッドの水平スワイプ

## 検索

- `Ctrl+F` またはタイトルバーの検索ボタンで検索バーを表示
- `Enter` / `F3` で次のマッチへ移動
- `Shift+Enter` / `Shift+F3` で前のマッチへ移動
- `Ctrl+G` / `Ctrl+Shift+G` でも次/前のマッチへ移動可能
- 大文字/小文字の区別を切替可能
- 全マッチのハイライト表示を切替可能
- `Escape` で検索バーを閉じる

## キーボードショートカット

| キー | 機能 |
|---|---|
| `Ctrl+O` | ファイルを開く |
| `Ctrl+C` | 選択テキストをコピー |
| `Ctrl+Shift+C` | 選択テキストを書式付き（HTML）でコピー |
| `Ctrl+A` | すべて選択 |
| `Ctrl+1` | ファイルペインの表示切替 |
| `Ctrl+2` | 目次ペインの表示切替 |
| `Ctrl++` / `Ctrl+-` | ズームイン / ズームアウト |
| `Ctrl+0` | ズームをリセット |
| `Ctrl+マウスホイール` | ズームイン / ズームアウト |
| `Ctrl+F` | 検索バーを開く |
| `F3` / `Shift+F3` | 次/前のマッチへ移動 |
| `Alt+←` / `Alt+→` | 戻る / 進む |
| `F1` | このヘルプを表示 |
| `F5` | ファイルを再読み込み |
| `Escape` | 選択を解除 / 検索バーを閉じる |

## 便利な機能

- **目次ペイン**: 目次の見出しをクリックしてジャンプ
- **ファイルペイン**: 上部のボタンで表示中ファイルのフォルダへ移動・一覧の更新
- **ペインの表示切替**: タイトルバーのボタンまたは右クリックメニューからファイルペイン・目次ペインを表示/非表示
- **ライブリロード**: 表示中のファイルが更新されると自動で再読み込みし、変更箇所へスクロール
- **リンク**: クリックで外部リンクをブラウザで開く / ページ内の見出しへジャンプ
- **コードブロックのコピー**: コードブロック右上のコピーボタンをクリック
- **書式付きコピー**: `Ctrl+Shift+C` または右クリックメニューの「書式付きコピー」で、見出し・強調・リンク等の書式を保った HTML リッチテキストをクリップボードへ。Word や Outlook 等に貼ると書式が保持されます。
- **ダイアグラムの保存・コピー**: Mermaid図や数式の右上のボタンでPNG画像として保存、またはクリップボードにコピー
- **エディタで開く**: 右クリックメニューの「エディタで開く」で表示中のファイルを既定のエディタで開く
- **ダークモード**: タイトルバーのボタンまたは右クリックメニューから切替
- **ペイン幅の調整**: ペイン境界をドラッグしてリサイズ
- **ウィンドウ位置のリセット**: タスクバーのボタンを右クリックし「ウィンドウ位置をリセット」
