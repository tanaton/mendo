# mendo 操作ガイド

軽量・高速な Markdown ビュアーです。

## ファイルを開く

- ファイルをウィンドウにドラッグ＆ドロップ
- `Ctrl+O` でファイル選択ダイアログを表示
- 左側のファイルペインからクリック

## スクロール

- マウスホイールでスムーズスクロール
- `↑` / `↓` キーで行単位スクロール
- `PageUp` / `PageDown` でページ単位スクロール
- `Home` / `End` で先頭・末尾へジャンプ

## 戻る・進む

- `Alt+←` / `Alt+→`
- マウスのサイドボタン（戻る/進む）
- 右クリックしながら左右にドラッグ（マウスジェスチャー）
- タッチパッドの水平スワイプ

## キーボードショートカット

| キー | 機能 |
|---|---|
| `Ctrl+O` | ファイルを開く |
| `Ctrl+C` | 選択テキストをコピー |
| `Ctrl+A` | すべて選択 |
| `Ctrl+1` | ファイルペインの表示切替 |
| `Ctrl+2` | 目次ペインの表示切替 |
| `Ctrl++` / `Ctrl+-` | ズームイン / ズームアウト |
| `Ctrl+0` | ズームをリセット |
| `F1` | このヘルプを表示 |
| `F5` | ファイルを再読み込み |
| `Escape` | 選択を解除 |

## 便利な機能

- **目次ペイン**: 右側の目次から見出しをクリックしてジャンプ
- **コードブロックのコピー**: コードブロック右上のコピーボタンをクリック
- **ダークモード**: 右クリックメニューから切替
- **ペイン幅の調整**: ペイン境界をドラッグしてリサイズ
