# mendo 使用指南

轻量、高速的 Markdown 查看器。

## 打开文件

- 将文件拖放到窗口中
- 按 `Ctrl+O` 或点击标题栏中的打开文件按钮，打开文件对话框
- 在左侧文件窗格中点击文件

## 滚动

- 鼠标滚轮平滑滚动
- `Up` / `Down` 方向键逐行滚动
- `PageUp` / `PageDown` 逐页滚动
- `Home` / `End` 跳到开头或末尾

## 后退 / 前进

- `Alt+Left` / `Alt+Right`
- 鼠标侧键（后退 / 前进）
- 按住右键向左或向右拖动（鼠标手势）
- 在触摸板上水平滑动

## 搜索

- 按 `Ctrl+F` 或点击标题栏中的搜索按钮，打开搜索栏
- `Enter` / `F3` 跳到下一个匹配
- `Shift+Enter` / `Shift+F3` 跳到上一个匹配
- `Ctrl+G` / `Ctrl+Shift+G` 也可以跳到下一个 / 上一个匹配
- 切换是否区分大小写
- 切换是否突出显示所有匹配
- `Escape` 关闭搜索栏

## 键盘快捷键

| 按键 | 操作 |
|---|---|
| `Ctrl+O` | 打开文件 |
| `Ctrl+C` | 复制所选文本 |
| `Ctrl+Shift+C` | 将所选文本复制为带格式的 HTML |
| `Ctrl+A` | 全选 |
| `Ctrl+1` | 显示 / 隐藏文件窗格 |
| `Ctrl+2` | 显示 / 隐藏目录窗格 |
| `Ctrl++` / `Ctrl+-` | 放大 / 缩小 |
| `Ctrl+0` | 重置缩放 |
| `Ctrl+鼠标滚轮` | 放大 / 缩小指针下方的区域（正文、文件窗格或目录窗格） |
| `Ctrl+F` | 打开搜索栏 |
| `F3` / `Shift+F3` | 下一个 / 上一个匹配 |
| `Alt+Left` / `Alt+Right` | 后退 / 前进 |
| `F1` | 显示本帮助 |
| `F5` | 重新加载文件 |
| `Escape` | 取消选择 / 关闭搜索栏 |

## 提示

- **目录窗格**：点击目录中的标题即可跳转到该处
- **文件窗格**：使用顶部的按钮转到当前文件所在的文件夹，或刷新列表
- **显示 / 隐藏窗格**：通过标题栏按钮或右键菜单切换文件窗格和目录窗格
- **自动重新加载**：打开的文件发生变化时会自动重新加载，并滚动到变化的位置
- **链接**：点击外部链接会在浏览器中打开，点击页内链接会跳转到对应标题
- **复制代码块**：点击代码块右上角的复制按钮
- **复制为 HTML**：按 `Ctrl+Shift+C` 或在右键菜单中选择“复制为 HTML”，即可在保留标题、强调、链接等格式的同时，将 HTML 富文本放入剪贴板。粘贴到 Word 或 Outlook 时会保留格式。
- **保存 / 复制图表**：将鼠标移到 Mermaid 图表或数学公式块上，使用右上角出现的按钮将其保存为 PNG 或复制到剪贴板
- **在编辑器中打开**：在右键菜单中选择“在编辑器中打开”，用默认编辑器打开当前文件
- **设置**：点击标题栏中的齿轮按钮打开设置，可以切换显示语言（立即生效）或清除图表缓存
- **深色模式**：通过标题栏按钮或右键菜单切换
- **分区缩放**：正文、文件窗格和目录窗格各自拥有独立的缩放比例，也可以通过右键菜单中的“缩放”行（−、+、恢复）在菜单保持打开的状态下进行调整
- **调整窗格大小**：拖动窗格边框即可调整大小
- **重置窗口位置**：右键单击任务栏按钮并选择“重置窗口位置”
