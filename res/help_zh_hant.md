# mendo 使用說明

輕巧、快速的 Markdown 檢視器。

## 開啟檔案

- 將檔案拖放到視窗中
- 按 `Ctrl+O` 或按一下標題列中的開啟檔案按鈕，開啟檔案對話方塊
- 在左側檔案窗格中按一下檔案

## 捲動

- 滑鼠滾輪平滑捲動
- `Up` / `Down` 方向鍵逐行捲動
- `PageUp` / `PageDown` 逐頁捲動
- `Home` / `End` 跳到開頭或結尾

## 上一頁 / 下一頁

- `Alt+Left` / `Alt+Right`
- 滑鼠側鍵（上一頁 / 下一頁）
- 按住右鍵向左或向右拖曳（滑鼠手勢）
- 在觸控板上水平滑動

## 搜尋

- 按 `Ctrl+F` 或按一下標題列中的搜尋按鈕，開啟搜尋列
- `Enter` / `F3` 跳到下一個相符項目
- `Shift+Enter` / `Shift+F3` 跳到上一個相符項目
- `Ctrl+G` / `Ctrl+Shift+G` 也可以跳到下一個 / 上一個相符項目
- 切換是否區分大小寫
- 切換是否醒目提示所有相符項目
- `Escape` 關閉搜尋列

## 鍵盤快速鍵

| 按鍵 | 操作 |
|---|---|
| `Ctrl+O` | 開啟檔案 |
| `Ctrl+C` | 複製所選文字 |
| `Ctrl+Shift+C` | 將所選文字複製為帶格式的 HTML |
| `Ctrl+A` | 全選 |
| `Ctrl+1` | 顯示 / 隱藏檔案窗格 |
| `Ctrl+2` | 顯示 / 隱藏目錄窗格 |
| `Ctrl++` / `Ctrl+-` | 放大 / 縮小 |
| `Ctrl+0` | 重設縮放 |
| `Ctrl+滑鼠滾輪` | 放大 / 縮小指標下方的區域（內文、檔案窗格或目錄窗格） |
| `Ctrl+F` | 開啟搜尋列 |
| `F3` / `Shift+F3` | 下一個 / 上一個相符項目 |
| `Alt+Left` / `Alt+Right` | 上一頁 / 下一頁 |
| `F1` | 顯示本說明 |
| `F5` | 重新載入檔案 |
| `Escape` | 取消選取 / 關閉搜尋列 |

## 提示

- **目錄窗格**：按一下目錄中的標題即可跳到該處
- **檔案窗格**：使用上方的按鈕前往目前檔案所在的資料夾，或重新整理清單
- **顯示 / 隱藏窗格**：透過標題列按鈕或右鍵選單切換檔案窗格和目錄窗格
- **自動重新載入**：開啟的檔案有變更時會自動重新載入，並捲動到變更的位置
- **連結**：按一下外部連結會在瀏覽器中開啟，按一下頁內連結會跳到對應的標題
- **複製程式碼區塊**：按一下程式碼區塊右上角的複製按鈕
- **複製為 HTML**：按 `Ctrl+Shift+C` 或在右鍵選單中選擇「複製為 HTML」，即可在保留標題、強調、連結等格式的同時，將 HTML 富文字放入剪貼簿。貼到 Word 或 Outlook 時會保留格式。
- **儲存 / 複製圖表**：將滑鼠移到 Mermaid 圖表或數學公式區塊上，使用右上角出現的按鈕將其儲存為 PNG 或複製到剪貼簿
- **在編輯器中開啟**：在右鍵選單中選擇「在編輯器中開啟」，以預設編輯器開啟目前的檔案
- **設定**：按一下標題列中的齒輪按鈕開啟設定，可以切換顯示語言（立即生效）或清除圖表快取
- **深色模式**：透過標題列按鈕或右鍵選單切換
- **分區縮放**：內文、檔案窗格和目錄窗格各自擁有獨立的縮放比例，也可以透過右鍵選單中的「縮放」列（−、+、還原）在選單保持開啟的狀態下調整
- **調整窗格大小**：拖曳窗格邊框即可調整大小
- **重設視窗位置**：在工作列按鈕上按一下右鍵並選擇「重設視窗位置」
